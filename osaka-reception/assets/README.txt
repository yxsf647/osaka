LOGO
  Save the Osaka Wings logo here as:  assets/logo.png
  (If it is missing, the logo from www.osakawings.co.ke is used.)

CAR PHOTOS (JPEG)
  Put photos in:  assets/cars/
  Name each file exactly like the 'image' value in data/cars.php, e.g.
     assets/cars/toyota-prado-kakadu.jpeg
  Extra photos for the same car (rotate on screen):
     assets/cars/toyota-prado-kakadu-2.jpeg, -3.jpeg ...
  .jpg is also accepted.
